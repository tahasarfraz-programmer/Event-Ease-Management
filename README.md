# EventEase - Online Event Management & Venue Booking System

## Requirements
- PHP 8+
- MySQL/MariaDB
- XAMPP recommended

## Installation
1. Copy `EventEase` to `xampp/htdocs/`.
2. Start Apache and MySQL.
3. Open phpMyAdmin and import `database/eventease_db.sql`.
4. Update database credentials in `config/database.php` if needed.
5. Open `http://localhost/EventEase/`.

## Demo Accounts

## Main Features
- Role based authentication
- Admin dashboard
- Organizer event management
- Participant registration
- Categories, events, tickets, venues
- Registration and payment records
- Notifications
- Responsive Bootstrap design
